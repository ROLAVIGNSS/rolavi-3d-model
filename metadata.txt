about=ROLAVI 3D Model brings photogrammetry and LiDAR 3D models into a real coordinate system and exports them as SLPK (I3S).
    - Import textured OBJ, PLY meshes, PLY point clouds and 3D Gaussian splats (3DGS), including ROLAVIScan files placed with their own georeference.
    - Place the model in any CRS (EPSG search, projected or geographic) and adjust it with ground control points (similarity transform, residuals per point).
    - Optional geoid (GTX grid) for orthometric heights.
    - Export WGS84 Scene Layer Packages: IntegratedMesh I3S 1.7 for meshes, PointCloud I3S 2.0 for point clouds.
    - 2D and 3D views, base maps, and a layer list.
    - GeoTIFF orthomosaics and DEMs in the 2D view; cut and fill volumes between two DEMs or between a DEM and a base elevation, inside polygons from Shapefile, DXF, KML, KMZ or drawn on the map.
    - Optional: send models, DEMs, orthomosaics and vector layers to a ROLAVI Viewer account (https://viewer.rolavi.net). Everything else works without an account.
    Requirements: numpy and Pillow (both included with QGIS for Windows). pyproj is used when present, otherwise the QGIS coordinate engine.
    Optional 3D view: pyvista and pyvistaqt. Windows: close QGIS, open the OSGeo4W Shell and run "python -m pip install pyvista pyvistaqt". macOS / Linux: install them in the Python that QGIS uses. Without them the plugin works with the 2D view.
